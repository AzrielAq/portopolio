# Portofolio Azriel Aqilla

Website portofolio statis (HTML, CSS, JavaScript) tanpa framework.

## Cara mengedit
- `index.html`: ganti teks, proyek, keahlian, email, dan link media sosial (cari `USERNAME` dan `emailanda@gmail.com`).
- `style.css`: warna ada di bagian `:root` paling atas.
- `script.js`: tema gelap/terang dan efek huruf pada nama.

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `portfolio`.
2. Upload semua file di folder ini (Add file → Upload files), lalu Commit.
3. Buka Settings → Pages → Branch: `main` / folder `/ (root)` → Save.
4. Tunggu 1–2 menit, website tampil di `https://USERNAME.github.io/portfolio/`.
